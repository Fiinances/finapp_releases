## 🚀 Por que escolher o Finapp?

> **Você trabalha duro pelo seu dinheiro. O Finapp trabalha duro para que você saiba exatamente onde ele está.**

O Finapp é um aplicativo desktop de finanças pessoais desenvolvido para quem quer **controle real**, **privacidade total** e **zero dependência da nuvem**. Gerencie contas bancárias, cartões de crédito, importações de extratos e muito mais — tudo rodando direto na sua máquina.

## 📥 Como instalar

1. Acesse a página de [**Releases**](https://github.com/Fiinances/finapp_releases/releases/latest)
2. Baixe o instalador para o seu sistema operacional (Windows, macOS ou Linux)
3. Execute o instalador e pronto — **sem cadastro, sem configuração de nuvem**
4. Adicione sua primeira conta bancária e comece a ter controle total das suas finanças
